## 三、奖项与评判取向（品质标准）

- 德国 iF 设计奖（iF Design Award）
- 美国 MUSE 设计奖 铂金奖（MUSE Design Awards Platinum）

评判取向（用于方案自检与评审把关）：
1. 概念是否成立——有没有清晰的设计主题与叙事，而非灯具堆砌。
2. 层次与节奏——载体 / 氛围 / 焦点 / 动线是否分明，有无主次。
3. 舒适度——眩光控制、色温统一、夜间友好（不刺眼、不影响周边）。
4. 落地性与运维——造价可控、节能可控、维护便利。
5. 场所价值——是否真正服务商业、文化或人群体验。

## 四、常用硬性技术指标（出技术标 / 评审用）

- **色温（CCT）**：文旅文化院多偏暖（2700K–3000K）；商业 / 现代建筑可 3000K–4000K；慎用高色温冷白做大面积。
- **显色指数（CRI / Ra）**：重点照明、商业、文化展示建议 Ra≥90；一般环境 Ra≥80。
- **眩光控制**：优先小角度精准投光 + 遮光角（cutoff）灯具，避免上射光污染；住区 / 广场周边严控溢光。
- **能耗与智能**：按场景分时控制（平日低能耗模式 / 节假日全亮 / 深夜低位运行）；优先 LED + 调光 + 智能回路。
- **防护与维护**：室外灯具防护等级（IP65 起步，水景 / 地面更高）、散热、可维护更换设计。

## 五、智能照明控制策略

- 分场景模式：平日、周末、节假日、深夜各一套亮度 / 动态策略。
- 分区分回路：按载体、氛围、焦点、动线独立回路，便于运维与节能。
- 适度动态：文化 / 商业项目可设轻动态，"讲故事"而非常亮跑马灯。
- 可管可控：预留集中控制与故障监测，降低长期运维成本。

## 六、投标技术标 / 奖项申报要点

- 结构：项目理解 → 设计主题与叙事 → 照明策略（层次 + 手段）→ 技术指标 → 落地保障（样灯 / 样板段 / 施工配合 / 运维）。
- 先价值后技术：开头讲清"为这个场所解决什么问题、创造什么体验"，再展开技术。
- 用作品说话：引用已落地获奖案例增强可信度。
- 量化可控：色温、显指、能耗、防护等级、回路策略尽量给具体数值与方案。

## 七、避坑清单（评审 / 改稿直说的问题）

- 彩虹色温、disco 动态、平均打亮无主次。
- 眩光刺眼、溢光扰民、上射光污染。
- 只讲意境不给布灯图 / 节点大样 / 样灯验证。
- 智能控制堆功能、不省电、不好用。
- 方案不提造价与维护成本，对业主不负责。
